# Changelog

## 0.1.3

- Add dedicated Home Assistant app icon and logo artwork.

## 0.1.2

- Expose Ollama on the standard host port 11434 after replacing the legacy app.

## 0.1.1

- Enable Ollama's integrated-GPU path after Vulkan verifies Intel HD Graphics 630.

## 0.1.0

- Initial release with Ollama 0.35.0.
- Adds the Mesa Intel Vulkan runtime for Intel integrated GPUs.
- Requires a verified GPU by default, preventing silent CPU fallback.
